A game community’s own tooling, kept running past the people who shipped the game.

IThe account

A revival project for Mercenaries 2: World in Flames (Mercenaries2 e51dcbe README.md:9), with online play through refesl.live (Mercenaries2 e51dcbe README.md:145). Its mod line continues in Merc2-Mods-Exp: the project's own pointer to where that work moved (Mercenaries2 e51dcbe README.md:5: “For the mods developed during this phase of the project, visit [Merc2-Mods-Exp]”). The same README points all further mods to the community Modkit: the project's own pointer to mercs2-modkit (Mercenaries2 e51dcbe README.md:6: “For the community Modkit/Mod Manager that all further mods will be built around, visit [mercs2-modkit]”).

Ess, the foundational Lua library for Mercenaries 2 modding (mercs2-lua-essentials 3430c0b README.md:3), is one of 22 (GitHub snapshot 2026-10-08) public mercs2 repositories under Logan's own account.

The Mercenaries-Fan-Build organisation's repositories that this site pins, each in its own README's words:

  • mercs2-modkit: A desktop mod manager for Mercenaries 2: World in Flames (Mercenaries-Fan-Build/mercs2-modkit 9acb750 README.md:3); its README also says that Mercenaries 2 is a 32-bit Windows game, so on macOS and Linux Modkit launches it through Wine or Proton (Mercenaries-Fan-Build/mercs2-modkit 9acb750 README.md:52).
  • mercs2-qol-mods: A collection of quality-of-life mods for Mercenaries 2: World in Flames (PC) (Mercenaries-Fan-Build/mercs2-qol-mods 6f1fc59 README.md:3).
  • mercs2-wad-simulator: A Rust workspace for Mercenaries 2 WAD analysis, asset extraction, and Xbox-to-PC conversion (Mercenaries-Fan-Build/mercs2-wad-simulator d18af76 README.md:3); its qm binary lints and builds Shipments, the mod package format (Mercenaries-Fan-Build/mercs2-wad-simulator d18af76 README.md:8: “Lints and builds Shipments: the mod package format (a manifest.yaml plus a src/ directory)”).
  • notes-on-the-released-game: Tooling, research notes, and a from-scratch engine for Mercenaries 2: World in Flames (Mercenaries-Fan-Build/notes-on-the-released-game dac773d README.md:3).

The credits below name every contributor to Mercenaries2, Merc2-Mods-Exp and mercs2-lua-essentials, and to the organisation's repositories listed above; no other repository is covered.
