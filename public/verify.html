IWays to check this

Don't trust this - run one.

  1. cft-fp256's own conformance replay, in the browser. Cost: a browser tab, nothing installed. It replays the published conformance vectors in front of you (cft-fp256 77b8440 README.md:30).
  2. make golden in a clone of cft-fp256. Cost: 2.6 min at four workers (cft-fp256 77b8440 docs/VERIFICATION.md:173). The golden model's self-tests (cft-fp256 77b8440 README.md:254): Its pytest suite checks the model against its own invariants and against mpmath and MPFR where they can arbitrate (cft-fp256 77b8440 docs/VERIFICATION.md:37). Nothing below re-litigates a value it has decided (cft-fp256 77b8440 docs/VERIFICATION.md:39).
  3. make verify-quick. Cost: ~20 min, 28 of 41 stages (cft-fp256 77b8440 CLAUDE.md:9). `quick` is the docs, generated, buildargs and sweepjudge checks, the model-versus-C stages, the GPU's photograph, the bindings, the language legs, the soak spot check, the workloads, the demos and the remote backend (cft-fp256 77b8440 docs/VERIFICATION.md:209); it does not run the golden suite, the vectors, the library replay, the transcendentals, MPFR, the C++ replay, lint and formal (cft-fp256 77b8440 docs/VERIFICATION.md:213) - those need make verify-gate. And, CI's green tick does not cover synthesis, timing or silicon (cft-fp256 77b8440 README.md:247).
  4. python site/build.py --verify-facts in a clone of this site. Cost: one read per figure this site prints, at its pin or from the committed GitHub snapshot; a private repository's read is skipped by name. It proves every figure this site prints - including every quote above - is still exactly what its source gives right now; it does not prove that source's own claim is true, and a stated word has no source to re-read at all.
