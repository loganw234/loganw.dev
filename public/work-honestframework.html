IWhat it is

A way to lay out a project so that an AI can write nearly all of it and no claim about it ever rests on the AI's judgement (HonestFramework 65447fd README.md:3).

IIWhat it is not

  • Not a prompting guide. Nothing here depends on phrasing, model, or version. The mechanisms are files and exit codes (HonestFramework 65447fd README.md:110)
  • Not a substitute for tests. It is a set of properties your tests and build must have before their green means anything (HonestFramework 65447fd README.md:113)
  • Not free. A project built this way carries a reference implementation it could have done without, a second copy of some checks, and a ledger that only grows (HonestFramework 65447fd README.md:116)
  • Not about distrusting the agent. The agent in the case study wrote essentially all of 743,605 lines across six repositories, including every mechanism described here, and found most of the defects listed in it (HonestFramework 65447fd README.md:122)

IIIThe contract

That is the whole thesis in one example (HonestFramework 65447fd README.md:105). The agent wrote every line of the fix (HonestFramework 65447fd README.md:105). It decided nothing about whether the fix worked (HonestFramework 65447fd README.md:106).
