Design experiments

One Home page, five ways of looking. The content is the same in every one — the same figures, read from the same 13 pinned commits — so what differs is only the type, the colour, and how a figure shows where it came from.

Chosen so far

Logan, 2026-09-29: “D looks good, but the color scheme of A (the blue), and the font and header choice of B.” That is E. A to D stay as they were, as the record of the options.

The same in every one

  • The map: position across is a date read from git, and every arrow names the file that says so.
  • The ledger, with the spec's columns, plus agent-written and with last verified renamed last entry, because a ledger's newest heading is not always a run of its gate.
  • The biography and anything else no file backs are marked stated, never sourced.
  • No script, no analytics, one colour, real tables, numbers in mono.

What these are not

  • Not the site. Only Home exists, and the other eight entries in the navigation do nothing.
  • Not final copy. The biography is a draft of the spec's three sentences.
  • Not self-hosted: every page but D loads fonts from Google Fonts. The site would serve its own.
